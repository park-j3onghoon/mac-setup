# Productivity

- [explain-html](./explain-html/SKILL.md): 개념·설계·코드 흐름을 그림이 든 HTML 해설서로 설명해 달라고 할 때, 주제를 조사해 인라인 SVG 도식이 들어간 단일 파일 HTML 해설서를 만들고 ~/plans에 저장한 뒤 브라우저로 연다. 채팅 답으로 충분한 설명에는 쓰지 않는다.
- [mastery-tutor](./mastery-tutor/SKILL.md): 슬랙 스레드나 개념을 배울 목적에 맞춰 나머지를 여는 핵심 3개로 좁히고, 핵심마다 판단 문제 3개를 한 번에 하나씩 낸다. 틀린 답은 그 답을 만든 가정을 짚어 다시 생각하게 하고, 문제를 마칠 때마다 전문가의 판단 과정을 보인 모범 풀이와 진척을 보인다. 학습 정리·오답·진행 상황을 Codex와 Claude 공용 로컬 기록에 저장해 이전 학습을 재사용하고 중단 뒤 이어서 할 수 있다. "완전히 이해할 때까지 질문해", "퀴즈로 공부하자", "전에 하던 학습 이어서"에 쓴다. 단순 요약이나 일회성 개념 설명에는 쓰지 않는다.
- [refresh-session](./refresh-session/SKILL.md): 사용자가 새 세션에서 이어 가자고 할 때, 다음 작업을 새 프로세스의 빈 컨텍스트에서 잇는다. Claude Code·Codex 둘 다 지금 세션을 끄고 같은 cmux 탭에서 다시 띄우거나(Claude Code는 설치된 최신 버전으로) 새 탭 명령을 만든다. 지금 세션에서 이어 하는 작업에는 쓰지 않는다.
- [rules-refresh](./rules-refresh/SKILL.md): AI 규칙을 다시 짜거나 주기 갱신·PR 대조를 해 달라고 할 때, AI 규칙(진입 파일·lib·instructions·스킬·검사 스크립트)을 개발 방법론과 Simple Design 기준에 맞춰 다시 짜고, 매주 바뀐 것만 갱신하며, 매달 지난달 머지 PR로 리뷰 규칙을 리뷰봇·사람 리뷰와 대조한다. 정해진 문장을 고치는 요청에는 쓰지 않는다.
