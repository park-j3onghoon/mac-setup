# Productivity

일상적인 비코드 업무 도구.

전부 **User-invoked** 다. 사람이 `/이름` 을 칠 때만 실행되고(`disable-model-invocation: true`), 모델이나 다른 스킬은 부를 수 없다.

- **[explain-html](./explain-html/SKILL.md)**: 주제를 조사해 인라인 SVG 도식이 들어간 단일 파일 HTML 해설서를 만들고, ~/plans에 저장한 뒤 브라우저로 연다.
- **[new-session](./new-session/SKILL.md)**: 다음 작업을 새 세션에서 바로 시작할 셸 명령 한 줄을 모델·effort와 함께 만들어 보여 주고 클립보드에 복사한다.
- **[skill-review](./skill-review/SKILL.md)**: 스킬이 구조 규약과 실행 기준을 지키는지 점검하고, 어긋난 곳을 고칠 안을 낸다.
