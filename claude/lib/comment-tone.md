## 공통

- 문장은 `~습니다`로 끝낸다. 판단·짐작·제안은 `것 같습니다` 대신 `거 같습니다`로 끝낸다: "중복되는 거 같습니다."
- 코드 위치와 예시 입력의 결과는 `~됩니다`, `~있습니다`로 단정하고, 들은 말 대신 확인한 근거를 쓴다.
- 덧붙이는 관찰은 `~네요`로, 앞 문장의 이유는 `~해서요.`로 끝낸다: "다른 모듈에서는 `{이름}`을 썼네요.", "운영 전에 바꾸면 QA를 다시 해야 해서요."
- `!`는 감사·동의·마무리 문장 끝에만 붙인다.
- 평문 문장으로 쓰고 코드 이름만 백틱으로 감싼다. 갈래가 둘 이상이면 `1.`, `2.` 줄로 나누고, 예시 입력과 코드는 코드 블록으로 붙인다.
- 나열은 쉼표와 조사(`와`, `나`)로 잇고, 덧붙일 내용은 괄호 대신 다음 문장으로 쓴다.
- 한 문장이 70자를 넘으면 두 문장으로 나눈다. 백틱과 코드 블록 안 글자는 세지 않는다.

## 리뷰 코멘트

- 줄 코멘트 하나는 문제를 짚는 문장 → 묻거나 권하는 문장 순서로 문장 1~3개에 쓴다. 틀어지는 예시를 붙일 때만 5개까지 쓴다.
- 문제를 짚는 문장은 `거 같습니다`로 끝낸다: "뒤 그룹이 실패하면 앞 그룹만 저장된 채 끝날 거 같습니다."
- 바뀐 조건문, 부분 저장, 빠진 로그처럼 의도일 수도 있는 문제는 문제 문장 바로 뒤에 묻는다: `의도하신 걸까요?`, `~한 이유가 있을까요?`, `~가 맞을까요?`, `~안 해도 될까요?`
- 틀어지는 경우는 `예를 들어`로 시작해 입력과 결과를 쓴다.
- 고칠 방법은 `~면 좋을 거 같습니다`, `~하는 건 어떨까요?`, `~하는 건 어떻게 생각하시나요?` 가운데 하나로 권하고, 이어지는 코멘트끼리는 다른 말을 고른다.
- 관례와 다른 코드는 `저희 코드는 ~`나 `다른 곳에서는 ~`로 관례를 먼저 쓰고 `특별한 이유가 없다면 ~ 맞추면 좋을 거 같습니다.`로 권한다.
- 같은 코드가 다른 곳에도 있으면 끝에 `참고로 {위치}에도 같은 코드가 있습니다.`를 붙인다.
- 머지를 막지 않는 사소한 지적은 첫 줄에 `nit)`나 `nit,`만 두고 다음 줄부터 쓴다.

```
이번에 `if ids is not None`이 `if ids`로 바뀌었는데, 빈 리스트가 오면 동작이 달라질 거 같습니다. 의도하신 동작일까요?
```

```
nit)
중복되는 거 같은데 `conftest.py`로 옮기는 건 어떨까요?
```

## 리뷰 본문

- 승인 본문은 `LGTM!`, `LGTM`, `LGTM~` 가운데 하나를 한 줄로 쓴다.
- 줄에 달지 못한 사소한 지적은 승인 줄 아래 빈 줄 뒤에 리뷰 코멘트 꼴로 붙인다.
- 승인하지 않고 지적만 남기는 본문은 `확인 부탁드립니다!`나 `질문 {n}가지 남겼습니다.` 한 줄로 쓴다.
- 남의 PR 리뷰 본문에 승인 줄과 사소한 지적 말고 다른 문장이 들면 마지막 줄에 `수고하셨습니다!`를 둔다.

```
LGTM!

nit)
지금은 로그에만 남아서 3개월이 지나면 찾을 수 없을 거 같습니다. 오래 볼 기록이면 따로 남겨 두면 좋을 거 같습니다.
```

## 답글

- 동의하는 대답은 `네`로 시작한다.
- 반영한 지적에는 바꾼 내용 한 문장과 감사 한 문장을 쓴다: "말씀하신 방향이 좋은 거 같아서 공용 함수로 옮겼습니다. 꼼꼼히 봐주셔서 감사합니다!"
- 놓친 것을 고쳤으면 `제가 놓쳤네요.`나 `깜빡했네요.`로 시작한다.
- 반영하지 않는 지적에는 `네 의도한 동작입니다.` 뒤에 이유 한 문장을 쓴다.
- 나중에 할 일은 `~하도록 하겠습니다!`로 끝낸다.
- 상대 설명을 받아들일 때는 `네 이해했습니다. 설명 감사합니다!`나 `그렇군요. ~라면 이대로 가도 좋을 거 같습니다!`로 쓴다.
- 다시 봐 달라고 할 때는 첫 줄에 `@{login}`만 두고 다음 줄에 `수정했습니다. 확인 부탁드립니다!`를 쓴다.
- 리뷰어가 낸 갈래는 `전자`, `앞쪽 경우` 대신 그 내용을 문장으로 다시 쓴다.
- 감사 문장은 사람 리뷰어에게 단 답글에만 붙인다. 답글이 여럿이면 첫 문장과 감사 문장을 답글마다 다르게 고른다: `꼼꼼히 봐주셔서 감사합니다!`, `꼼꼼한 리뷰 감사합니다!`, `의견 감사합니다!`, `감사합니다!`
