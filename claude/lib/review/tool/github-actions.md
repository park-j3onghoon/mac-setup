- 서드파티 액션을 태그나 브랜치로 참조하면 지적하고 커밋 SHA로 고정하게 한다.
- 워크플로가 개인 토큰(PAT)을 쓰면 지적하고 GitHub App 토큰으로 바꾸게 한다.
- 워크플로에 시크릿 값을 직접 쓰면 지적하고 저장소 secrets나 Vault에서 읽게 한다.
- `permissions`가 없거나 잡이 쓰지 않는 쓰기 권한(`pull-requests: write`, `contents: write`)을 주면 지적하고, 잡에 필요한 권한만 남기게 한다.
- 결과를 아무도 쓰지 않는 step(설치만 하고 쓰지 않는 도구)이 있으면 지적하고 지우게 한다.
- 실행마다 도구를 소스에서 빌드하면(`go run`) 지적하고 빌드된 바이너리나 캐시를 쓰게 한다.
- 새 디렉터리를 더했는데 `CODEOWNERS`에 담당자가 없으면 지적한다.
