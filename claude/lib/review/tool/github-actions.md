- 서드파티 액션은 태그나 브랜치 대신 커밋 SHA로 고정해 참조한다.
- 워크플로는 개인 토큰(PAT) 대신 GitHub App 토큰을 쓴다.
- 워크플로의 시크릿은 값을 직접 쓰는 대신 저장소 secrets나 Vault에서 읽는다.
- `permissions`에는 잡이 쓰는 권한만 적는다(쓰지 않는 `pull-requests: write`, `contents: write`는 뺀다).
- 결과를 아무도 쓰지 않는 step(설치만 하고 쓰지 않는 도구)은 지운다.
- CI가 쓰는 도구는 실행마다 소스에서 빌드하는(`go run`) 대신 빌드된 바이너리나 캐시를 쓴다.
- 새 디렉터리를 더하면 `CODEOWNERS`에 담당자를 적는다.
