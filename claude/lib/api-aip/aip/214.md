```proto
message ExpiringResource {
  // google.api.resource 등 다른 annotation·필드
  oneof expiration {
    // UTC 만료 시각; 출력엔 늘 채우고, 생성 때 ttl을 줬으면 그 값으로 계산한다.
    google.protobuf.Timestamp expire_time = 2;
    // Input only. 이 리소스의 TTL.
    google.protobuf.Duration ttl = 3 [(google.api.field_behavior) = INPUT_ONLY];
  }
}
```
- 만료를 나타내려면 반드시 `google.protobuf.Timestamp expire_time` 필드를 쓴다.
- 상대 만료 시간을 받으려면 반드시 `expiration`(또는 `{something}_expiration`)이라는 `oneof`를 정의하고 그 안에 `expire_time`과 별도의 `google.protobuf.Duration ttl`을 둔다; `ttl`은 반드시 `INPUT_ONLY`로 표시한다.
- 리소스를 조회할 땐 반드시 만료 시각을 `expire_time`에 담아 돌려주고 `ttl`은 비운다.
- TTL 고유의 의미에 기대는 API(TTL을 정수로 표현해야 하는 DNS 등)는 `int64 ttl` 필드를 써도 되고, 그 경우 `aip.dev/not-precedent` 주석(AIP를 어긴 이유를 적어 선례로 복사되지 않게 하는 내부 주석)을 단다(권장).
