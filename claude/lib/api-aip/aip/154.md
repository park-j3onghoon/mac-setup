- 클라이언트가 최신 상태임을 보장해야 하는 리소스엔 `etag`를 둬도 되고, declarative-friendly 리소스(`~/.claude/lib/api-aip/aip/128.md`)엔 반드시 둔다.
- 필드는 반드시 `string etag`(AIP 예시는 리소스의 `string etag = 99;`); 값은 서버가 다른 필드로 계산한 체크섬이다.
- 값은 RFC 7232처럼 따옴표를 포함한다(권장: `foo`가 아니라 `"foo"`); weak etag는 반드시 `W/` 접두어; strong·weak 중 무엇인지 문서화(권장).
- 요청의 etag가 현재 값과 다르면 반드시 `ABORTED`(다른 오류가 우선하지 않는 한), 같으면 반드시 허용; etag 없는 요청은 허용(권장); 강한 일관성·병렬성 요구가 있으면 항상 요구하고 없으면 `INVALID_ARGUMENT`로 거절해도 된다.
- 리소스의 etag엔 field_behavior를 달지 않고(권장), 요청 메시지의 etag엔 `REQUIRED`나 `OPTIONAL`을 단다(권장).
- Update는 리소스 본문의 etag를 그대로 쓰고, Delete·커스텀 메서드는 요청에 별도 필드를 둔다: `string etag = 2 [(google.api.field_behavior) = OPTIONAL];`.
