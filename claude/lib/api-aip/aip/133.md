rpc CreateBook(CreateBookRequest) returns (Book) {
  option (google.api.http) = {post: "/v1/{parent=publishers/*}/books" body: "book"};
  option (google.api.method_signature) = "parent,book,book_id";
}
message CreateBookRequest {
  string parent = 1 [(google.api.field_behavior) = REQUIRED,
    (google.api.resource_reference) = {child_type: "library.googleapis.com/Book"}];
  string book_id = 2 [(google.api.field_behavior) = REQUIRED];
  Book book = 3 [(google.api.field_behavior) = REQUIRED];
}

- 쓸모가 있으면 Create를 제공한다(권장); RPC 이름은 반드시 `Create` + 단수 리소스 이름, 요청은 반드시 `{RPC 이름}Request`, 응답은 반드시 리소스 자체이고 전부 채운다(권장).
- HTTP는 반드시 `POST`, `body`는 반드시 리소스 필드(`"book"`); URI 변수는 `parent` 하나(권장), 컬렉션 ID(`books`)는 반드시 리터럴, 나머지는 쿼리 파라미터(권장).
- `method_signature`는 하나(권장): ID 없이 `"parent,book"`, ID를 받으면 `"parent,book,book_id"`(최상위면 `"book,book_id"`).
- 최상위가 아니면 `parent`가 반드시 있고 REQUIRED(권장); 리소스 필드는 반드시 있다; `{resource}_id`는 관리 평면이면 반드시, 데이터 평면이면 권장.
- 사용자 지정 ID: `{resource}_id`를 선택으로 두고 비면 시스템이 생성해도 된다; ID는 반드시 리소스가 아닌 요청 메시지에 두고, 입력 리소스의 `name`은 반드시 무시한다.
- 같은 이름이 이미 있으면 반드시 `ALREADY_EXISTS`, 그 기존 리소스를 볼 권한이 없으면 반드시 `PERMISSION_DENIED`.

- 요청에 뼈대 밖의 필수 필드를 반드시 두지 않고, 다른 AIP가 정하지 않은 선택 필드도 두지 않는다(권장). 오류 확인 순서는 `~/.claude/lib/api-aip/aip/193.md`를 따른다.
