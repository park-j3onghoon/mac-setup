- `name`(string): 모든 리소스에 반드시, 첫 필드(권장), IDENTIFIER(`~/.claude/lib/api-aip/aip/203.md`); `_name` 접미사는 다른 종류의 이름에 쓰지 않는다(권장).
- `parent`(string): 컬렉션의 부모 리소스 이름, 대부분의 List·Create 요청에 쓴다(권장).
- `display_name`(string): 반드시 사용자가 바꿀 수 있는 사람용 이름; declarative-friendly 리소스(`~/.claude/lib/api-aip/aip/128.md`)엔 둔다(권장); 고유성 요구 없이 63자 이하(권장). 회사명 같은 공식 명칭은 `title`(권장).
- 사람·동물 이름은 반드시 `given_name`·`family_name`, `first_name`·`last_name`은 반드시 쓰지 않는다.
- `create_time`(Timestamp, OUTPUT_ONLY): 반드시 생성 시각(시작이든 완료든 된다). `update_time`(Timestamp, OUTPUT_ONLY): 사용자가 바꾸면 반드시 갱신, 서비스 내부 변경이면 갱신해도 된다. 둘 다 declarative-friendly면 둔다(권장).
- `delete_time`(Timestamp, OUTPUT_ONLY): 반드시 soft delete 시각, soft delete가 아니면 반드시 비운다.
- `expire_time`(Timestamp): 리소스가 더는 유효하지 않은 시각(권장); 부정확해도 되지만 그 전에 만료하면 반드시 안 된다. `purge_time`: soft delete된 리소스가 영구 삭제될 시각(권장), 그 전에 purge하면 반드시 안 된다.
- `annotations`(`map<string, string>`): 클라이언트 도구용 소량 메타데이터로 둬도 된다; 반드시 Kubernetes annotation 제한을 따르고 키는 점(`.`) 네임스페이스를 요구한다(권장).
- IP 주소 필드는 반드시 `string`, 이름 `ip_address` 또는 `_ip_address` 접미사(`resolved_ip_address`), 형식 `IPV4`·`IPV6`·`IPV4_OR_IPV6`을 명시(`~/.claude/lib/api-aip/aip/202.md`).
- `uid`(string, OUTPUT_ONLY): 시스템이 할당한 고유 ID, 반드시 UUID4이고 반드시 `UUID4` 형식 확장(`~/.claude/lib/api-aip/aip/202.md`)으로 명시; declarative-friendly면 둔다(권장).
