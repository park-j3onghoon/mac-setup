```proto
rpc CreateBook(CreateBookRequest) returns (google.longrunning.Operation) {
  option (google.api.http) = {post: "/v1/{parent=publishers/*}/books" body: "book"};
  option (google.longrunning.operation_info) = {
    response_type: "Book"
    metadata_type: "OperationMetadata"
  };
}
// Operation: string name = 1; google.protobuf.Any metadata = 2; bool done = 3;
//   oneof result { google.rpc.Status error = 4; google.protobuf.Any response = 5; }
```
- 오래 걸리는(기준 약 10초) 메서드는 최종 응답 대신 `google.longrunning.Operation`을 돌려준다(권장). 응답은 반드시 스트리밍이 아니다.
- `Operation`을 돌려주는 API는 반드시 `google.longrunning.Operations` 서비스를 구현하고, 자체 LRO 인터페이스나 복사한 `Operation` proto를 반드시 쓰지 않는다.
- `operation_info`는 반드시 달고 `response_type`·`metadata_type`을 반드시 둘 다 지정; 다른 패키지 타입이면 반드시 전체 이름(fully-qualified).
- `response_type`은 LRO가 아니었다면 돌려줬을 타입이고 `google.protobuf.Empty`는 피한다(권장, Delete는 예외); `metadata_type`도 Empty는 피한다(권장, 메타데이터가 절대 필요 없을 때만 예외); 메타데이터엔 진행률·부분 실패 등을 담는다.
- Create·Update·Delete도 `Operation`을 돌려줘도 된다; 진행 중인 리소스도 Get·List에 나오되 state enum(`~/.claude/lib/api-aip/aip/216.md`)으로 사용 불가를 표시(권장).
- 병렬 작업은 받거나 큐에 넣어도 되고, 거절하면 반드시 `ABORTED`와 이유를 돌려준다; declarative-friendly API(`~/.claude/lib/api-aip/aip/128.md`)는 기존 작업을 선점해도 된다.
- 시작을 막는 오류는 반드시 즉시 오류 응답, 실행 중 실패는 반드시 `Operation.error`에 담는다; 치명적이지 않은 오류는 metadata에 `google.rpc.Status`로 둬도 된다.
- 완료된 operation은 만료돼도 된다(기준 30일). `response_type`·`metadata_type` 변경은 하위 호환을 깬다.
- validate_only 요청엔 유효한 응답을 담은 완료(`done=true`) operation, 즉시 오류, 검증용 LRO 중 하나로 반드시 응답한다; 검증 성공이면 operation `name`을 비워도 된다.
