```proto
rpc GetBook(GetBookRequest) returns (Book) {
  option (google.api.http) = {get: "/v1/{name=publishers/*/books/*}"};
  option (google.api.method_signature) = "name";
}
message GetBookRequest {
  // Format: publishers/{publisher}/books/{book}
  string name = 1 [(google.api.field_behavior) = REQUIRED,
    (google.api.resource_reference) = {type: "library.googleapis.com/Book"}];
}
```
- RPC 이름은 반드시 `Get` + 단수 리소스 이름, 요청은 반드시 `{RPC 이름}Request`, 응답은 반드시 리소스 자체(`GetBookResponse` 없음); 리소스는 전부 채워 돌려준다(권장, 부분 응답은 `~/.claude/lib/api-aip/aip/157.md`).
- HTTP는 반드시 `GET`, `body`는 반드시 없음; URI 변수는 `name` 하나(권장), 나머지 필드는 쿼리 파라미터(권장); `method_signature`는 `"name"` 하나(권장).
- 리소스 이름 필드는 반드시 있고 이름은 `name`(권장), REQUIRED(권장), `resource_reference`로 타입을 반드시 밝히고 주석에 패턴을 적는다(권장).
- 요청에 뼈대 밖의 필수 필드를 반드시 두지 않고, 다른 AIP가 정하지 않은 선택 필드도 두지 않는다(권장). 오류 확인 순서는 `~/.claude/lib/api-aip/aip/193.md`를 따른다.
