- 반드시 `lower_snake_case`; 단어는 숫자로 시작하지 않고 앞·뒤·연속 밑줄이 없다(반드시); repeated 필드는 반드시 올바른 복수형(`books`), 단수 필드는 단수형(권장). JSON 쪽 이름은 자동 변환된다.
- 올바른 미국 영어(권장); 같은 개념엔 API 사이에도 같은 이름(권장); 불필요한 단어를 빼되 모호하거나 지나치게 일반적인 이름은 피한다(권장).
- 잘 알려진 약어는 약어로 쓴다(권장): `config`, `id`, `info`, `spec`, `stats`; 단위도 약어 접미사(권장): `distance_km`, `width_px`.
- 형용사는 명사 앞(권장): `collected_items`(`items_collected` 아님). 의도·동작을 담은 동사형 이름은 반드시 금지(`collect_items` 아님).
- 전치사(`with`, `for`, `at`, `by`)를 넣지 않는다(권장): `error_reason`(`reason_for_error` 아님); 수량의 `per`는 예외.
- boolean은 `is` 접두어를 뺀다(권장): `disabled`(`is_disabled` 아님); 빼면 예약어가 되는 경우만 예외.
- 임의 URI는 `uri`, URL만 담는 필드는 `url`(권장). 사람이 읽는 이름은 `display_name`, 공식 이름은 `title`(세부는 `~/.claude/lib/api-aip/aip/148.md`).
- 언어 키워드와 겹칠 이름(`new`, `class`, `import` 등)은 피하고, 감싸는 메시지와 같은 이름의 필드는 두지 않는다(둘 다 권장).
- 바이너리는 `bytes`(권장); 저장 단계부터 base64 문자열이면 이중 인코딩을 피하려 `string`을 써도 된다.
