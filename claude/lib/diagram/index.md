# 도식 형식

- 일렬 흐름·트리는 코드블록으로 그린다. 비교·매핑처럼 표로 끝나는 것은 markdown 표로 쓴다.
- 아래 모양은 도식만 HTML 파일로 그리고, 답의 도식 자리에는 그 파일 경로를 남긴다.
  - 양(건수·금액)이 분류 사이를 옮겨 가거나 셋 이상의 갈래로 나뉘면 `~/.claude/lib/diagram/sankey.md`를 Read해 생키 도식으로 그린다.
  - 데이터·요청이 여러 단계·시스템을 거치며 갈라지고 합쳐지는 흐름이나, 그런 경로 여럿 또는 변경 전후 흐름을 비교하면 `~/.claude/lib/diagram/flow-map.md`를 Read해 흐름 지도로 그린다.
  - 그 밖에 흐름이 갈라졌다 합쳐지거나 화살표가 교차하면, 또는 시퀀스·상태 전이·타임라인처럼 가로세로 배치가 둘 다 필요하면 `~/.claude/lib/explain-html.md`를 Read해 2. 작성 절과 3. 저장 · 열기 절을 따른다.
