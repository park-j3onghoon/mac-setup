입력은 작업 트리 경로·변경 파일과 범위·연결된 계획 파일이다. 규칙과 승인된 판단을 읽어 적용 기준으로 모은다.

1. `~/.claude/lib/coding/index.md`를 Read하고 변경이 닿는 모듈을 모두 Read한다. 각 모듈이 가리키는 스택 파일도 해당 언어일 때 Read한다. 규칙 사이의 우선순위는 index.md를 따른다.
2. 작업 레포의 CLAUDE.md·AGENTS.md를 Read하고 그 문서가 가리키는 레포 전용 규칙도 Read한다.
3. 레포 이름은 작업 트리에서 `git rev-parse --path-format=absolute --git-common-dir`로 얻은 공용 Git 디렉토리의 부모 디렉토리 이름으로 정한다. `~/.claude/lib/{레포 이름}-rules.md`가 있으면 Read한다.
4. proto 메시지·RPC나 REST 경로·요청·응답 필드를 바꾸면 `~/.claude/lib/api-aip/index.md`를 Read한다. 트랙과 현행 컨벤션 확정 절대로 형제 스펙을 확인하고 해당 트랙 파일을 Read해 적용 기준을 모은다. 기존에 확정한 엔벨로프·페이지네이션·에러 shape·필드 케이스와 승인된 보류 사유가 있으면 함께 기록한다.
5. 연결된 `plan.md`를 Read해 이번 범위·최신 승인·승인된 동작 차이·미확인 사항·미룬 판단을 모은다. 경로가 없으면 대화·PR·커밋에서 연결된 계획을 찾고, 거기에도 없으면 `~/.claude/lib/plans-path.md`를 Read해 해당 레포와 작업에 맞는 계획을 찾는다. 계획을 하나로 특정할 수 없으면 미확인으로 적고 출처가 확인된 최신 승인과 PR·커밋을 의도로 삼는다.

결과에는 적용 규칙 파일의 절대경로와 기준, 계획 파일 경로, 승인된 판단과 출처를 적는다. 추가 리뷰어나 다른 AI에도 이 결과를 전달한다.

→ 완료: 적용 규칙과 승인된 판단이 출처와 함께 모였고, API 변경이면 트랙과 현행 컨벤션이 정해졌다.
