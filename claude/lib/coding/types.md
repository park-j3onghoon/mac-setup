- Make illegal states unrepresentable: use an enum for a meaningful domain/API kind, state or mode even with two values (`kind: ExitKind`), and a boolean for an on/off flag (`verbose`); replace mutually exclusive booleans (`is_tp` + `is_sl`) with one enum; replace an optional field plus a same-root boolean (`take_profit` + `is_take_profit`) with one field; put fields that travel with a variant in a discriminated union; give a constrained value a constrained type.
- Execution choices: an internal branch label is not automatically a domain state. Compare a direct conditional or concrete processing data with an enum when the producer classifies an action only for the consumer to dispatch on it again; keep an enum when its values have an independent meaning or contract. Neither enums nor explicit branches are prohibited.
